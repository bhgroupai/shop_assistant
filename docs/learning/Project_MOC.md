# Shop Assistant Learning Curriculum (Map of Content)

Welcome to the Shop Assistant learning journey! This project is a Telegram shop assistant bot powered by LLMs for structured data extraction, semantic search, and autonomous customer interaction. 

Here is our structured path to mastering this codebase bit by bit:

1. **[[01_System_Overview_and_Models|System Overview & Models]]** - Learned that `models.py` uses frozen dataclasses as structured storage boxes for the whole pipeline, ensuring data isn't accidentally modified across scripts.
2. **[[02_Data_Pipeline_Fetch_and_Extract|Data Pipeline: Fetch & Extract]]** - How raw Telegram posts are scraped and converted into structured data using an LLM.
3. **[[03_Semantic_Search_and_Indexing|Semantic Search & Indexing]]** - How products are embedded into vectors and searched using cosine similarity.
4. **[[04_AI_Agent_and_Tools|AI Agent & Tools]]** - How the LLM agent decides which tool to call based on the customer's intent.
5. **[[05_Telegram_Bot_Integration|Telegram Bot Integration]]** - How the async bot handles messages, threads, and escalation to the human owner.
